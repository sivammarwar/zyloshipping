SECTION 3: VERCEL DEPLOYMENT (FRONTEND)
================================================================================

1. Install Vercel CLI:
   npm install -g vercel

2. Login to Vercel:
   vercel login

3. Deploy Frontend:
   cd frontend
   vercel
   
   Follow prompts:
   - Set up and deploy: Yes
   - Which scope: Your account
   - Link to existing project: No
   - Project name: zyloshipping
   - Directory: ./
   - Override settings: No

4. Configure Environment Variables:
   vercel env add NEXT_PUBLIC_API_URL
   vercel env add NEXT_PUBLIC_APP_URL
   vercel env add NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
   
   Or via Vercel Dashboard:
   - Go to Project Settings → Environment Variables
   - Add all variables from .env.local

5. Deploy to Production:
   vercel --prod

6. Configure Custom Domain:
   - Go to Vercel Dashboard → Domains
   - Add your domain: www.zyloshipping.com
   - Update DNS records as instructed

SECTION 4: RAILWAY DEPLOYMENT (BACKEND)
================================================================================

1. Create Railway Account:
   Visit: https://railway.app

2. Install Railway CLI:
   npm install -g @railway/cli

3. Login:
   railway login

4. Initialize Project:
   cd backend
   railway init
   
   Select: Create new project
   Name: zyloshipping-backend

5. Add PostgreSQL:
   railway add postgresql
   
   This automatically sets DATABASE_URL

6. Add Redis:
   railway add redis
   
   This automatically sets REDIS_URL

7. Configure Environment Variables:
   railway variables set JWT_SECRET="your-secret"
   railway variables set GROQ_API_KEY="your-key"
   railway variables set RAZORPAY_KEY_ID="your-key"
   railway variables set RAZORPAY_KEY_SECRET="your-secret"
   railway variables set STRIPE_SECRET_KEY="your-key"
   railway variables set RESEND_API_KEY="your-key"
   railway variables set ALGOLIA_APP_ID="your-id"
   railway variables set ALGOLIA_ADMIN_KEY="your-key"
   
   Or via Railway Dashboard:
   - Go to Variables tab
   - Add all environment variables

8. Configure Build Settings:
   Create railway.json:
   {
     "build": {
       "builder": "NIXPACKS"
     },
     "deploy": {
       "startCommand": "npm run start",
       "restartPolicyType": "ON_FAILURE",
       "restartPolicyMaxRetries": 10
     }
   }

9. Deploy:
   railway up
   
   Or connect GitHub:
   - Link GitHub repository
   - Enable auto-deploy on push

10. Run Migrations:
    railway run npx prisma migrate deploy
    railway run npx prisma generate

11. Get Public URL:
    railway domain
    
    Or create custom domain in Railway Dashboard

SECTION 5: DATABASE MIGRATION
================================================================================

Production Migration Steps:

1. Backup Current Database:
   pg_dump -U username -d zyloshipping > backup.sql

2. Test Migration Locally:
   DATABASE_URL="production-url" npx prisma migrate deploy --preview-feature

3. Run Production Migration:
   railway run npx prisma migrate deploy
   
   Or on your server:
   npx prisma migrate deploy

4. Verify Migration:
   railway run npx prisma studio
   
   Check all tables and relationships

5. Seed Production Data (if needed):
   railway run npx prisma db seed

Important Notes:
- Always backup before migration
- Test migrations on staging first
- Use --preview-feature flag for safety
- Monitor application during migration
- Have rollback plan ready

SECTION 7: SSL/HTTPS CONFIGURATION
================================================================================

Vercel (Automatic):
- SSL certificates automatically provisioned
- HTTPS enforced by default
- No configuration needed

Railway (Automatic):
- SSL certificates automatically provisioned
- Custom domains get automatic HTTPS

Custom Server (Manual):
1. Install Certbot:
   sudo apt-get install certbot python3-certbot-nginx

2. Obtain Certificate:
   sudo certbot --nginx -d zyloshipping.com -d www.zyloshipping.com

3. Auto-renewal:
   sudo certbot renew --dry-run
   
4. Configure Nginx:
   server {
     listen 443 ssl http2;
     server_name zyloshipping.com;
     
     ssl_certificate /etc/letsencrypt/live/zyloshipping.com/fullchain.pem;
     ssl_certificate_key /etc/letsencrypt/live/zyloshipping.com/privkey.pem;
     
     location / {
       proxy_pass http://localhost:4000;
       proxy_http_version 1.1;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection 'upgrade';
       proxy_set_header Host $host;
       proxy_cache_bypass $http_upgrade;
     }
   }

SECTION 9: BACKUP STRATEGY
================================================================================

Database Backups:

1. Automated Daily Backups:
   Railway: Automatic backups included
   
   Manual (cron job):
   0 2 * * * pg_dump -U user zyloshipping > /backups/db-$(date +\%Y\%m\%d).sql

2. Backup Retention:
   - Daily backups: 7 days
   - Weekly backups: 4 weeks
   - Monthly backups: 12 months

3. Backup Storage:
   - AWS S3
   - Google Cloud Storage
   - Cloudflare R2

4. Test Restore Procedure:
   psql -U user -d zyloshipping_test < backup.sql

Redis Backups:

1. Enable RDB Snapshots:
   save 900 1
   save 300 10
   save 60 10000

2. AOF Persistence:
   appendonly yes
   appendfsync everysec

File Backups:
- User uploads: Sync to S3/R2
- Product images: CDN with origin backup
- Logs: Rotate and archive

SECTION 11: CI/CD PIPELINE
================================================================================

GitHub Actions (.github/workflows/deploy.yml):

name: Deploy to Production

on:
  push:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '18'
      - run: npm ci
      - run: npm test
      - run: npx tsc --noEmit

  deploy-backend:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Deploy to Railway
        run: |
          npm install -g @railway/cli
          railway up --service backend

  deploy-frontend:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Deploy to Vercel
        run: |
          npm install -g vercel
          vercel --prod --token=${{ secrets.VERCEL_TOKEN }}
